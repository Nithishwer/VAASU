# VAASU

VAASU stands for “VAASU's A ABFEP Setup Utility.” It is the successor to
`abflow`, located at `/biggin/b211/reub0138/Projects/orexin/abflow_git`.

The goal is to refactor abflow into one cohesive package using modern standards,
removing unnecessary functionality and resolving broken dependencies.

## Coding preferences

- Write code that Nithish can quickly read, understand, and modify.
- Clarify ambiguous requirements and implement only what is needed.
- Prefer the smallest clear, correct solution; avoid speculative abstractions.
- Use descriptive names and keep related code together in focused modules.
- Follow existing conventions and add dependencies or files only when useful.
- Use short Python comments where purpose or reasoning is not obvious.
- Format Python code with Ruff and remove unnecessary code before finishing.
